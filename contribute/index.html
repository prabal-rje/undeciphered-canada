Open Canadian Cryptanalysis · Humans & LLMs Welcome

Help crack Canada's hidden history.

Undeciphered.ca is an independent, non-commercial Canadian historical cryptography project. Historians, archivists, hobbyists, and AI-assisted researchers are welcome to contribute raw Canadian ciphertexts, verified keys, decoding proofs, and archival notes via GitHub Issues. Please note: we accept cipher data and research submissions via Issues only; code contributions and Pull Requests are not accepted.

Verification & Author Credit (1 to 2 Weeks): Every submission is checked manually against the official primary archive and verified for deterministic cryptographic proof. Accepted contributors are credited on the cipher's own timeline (with exact percentage solved) and on the leaderboard below within 1 to 2 weeks. Please supply ciphertexts, keys, and archive links via Issues only (no code PRs).

Easy Contribution Spec for LLMs & Coding Agents

Using Claude, ChatGPT, Gemini, or a coding agent to research Canadian archives? Paste this JSON structure into a GitHub Issue (or run the gh CLI command below) so your proof can be verified cleanly. See also /llms.txt and CONTRIBUTING.md.

{
  "submissionType": "solve",
  "cipherId": "robertson-mcdonald-1819-mar04",
  "year": "1819",
  "title": "Colin Robertson's 1819 Fort Chipewyan Captivity Cipher",
  "sourceUrl": "https://pam.minisisinc.com/DIGITALOBJECTS/Access/HBCA%20Microfilm/1M176/B39-B-1.pdf#page=23",
  "shelfmark": "HBCA B.39/b/1, f. 20v",
  "cipherText": "Exact raw ciphertext transcribed from archive",
  "plainText": "Verified deterministic plaintext (uncertain words in [brackets])",
  "solvedPct": 100,
  "keySummary": "Exact cipher system, codebook edition, shift or substitution key",
  "contributor": {
    "name": "Your Name",
    "handle": "@github-handle",
    "role": "solver",
    "aiAssisted": true
  },
  "notes": "Cross-checks, folio numbers, and prior historical credit if any."
}
GitHub CLI One-Liner 
gh issue create --repo prabal-rje/undeciphered-canada \

  • Rule 1 · Ciphertexts, Keys & Research Only (No Code PRs)Submit raw ciphertexts, deterministic keys/shifts, decoded readings, and archival citations via GitHub Issues only. Pull Requests and site code contributions are prohibited and will be closed without review.
  • Rule 2 · Official Archive Link OnlyLink directly to LAC, Heritage Canadiana, ANOM, BAnQ, HBCA, Huntington, Peel, or Internet Archive. Never upload copyrighted third-party scans.
  • Rule 3 · Deterministic Proof, Zero GuessingInclude exact codebook edition, shift, key, or substitution mapping so any reviewer can reproduce every decoded word. Put uncertain words in [brackets].
  • Rule 4 · Rights-Holder & Takedown ContactAll cipher submissions, keys, and corrections go strictly through GitHub Issues above. Archives or rights holders requesting a citation update or excerpt removal may use our rights & takedown form.
